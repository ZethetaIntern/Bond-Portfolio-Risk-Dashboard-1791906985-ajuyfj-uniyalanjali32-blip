Bond Portfolio Risk Dashboard

Project Overview

A Power BI dashboard for analyzing bond portfolio composition, market value, yield, duration, convexity, and risk.

Tools Used

- Microsoft Power BI
- DAX
- Data Visualization

Dashboard Pages

1. Portfolio Overview
2. Duration & Convexity Analysis
3. Portfolio Risk Mapping
4. Yield Curve Analysis
5. Monte Carlo Risk Analysis
6. Portfolio Holdings & Composition

Key Insights

- Analyzed portfolio value and sector allocation.
- Evaluated bond yield, duration, and convexity.
- Explored portfolio risk using Monte Carlo scenarios.

Completed as part of a Zetheta internship assignment.
